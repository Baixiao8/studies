# 木材知识

> 木板材通识报告：从木材基础（软硬木、Janka 硬度、含水率与胀缩）到常见木种图鉴、人造板与环保等级、按用途选材、加工使用规矩——为白笑后续上手木工与选购板材打底。

- **当前版本**：v0.2
- **最近更新**：2026-07-22
- **入口**：./index.html（对外分享用 ./index-standalone.html，图片已内嵌）

## 内容结构

单文件 HTML 报告（「看」轨·长文阅读版式），五章由浅入深：

1. **木材基础**——心材边材、软硬木分类真相、Janka 硬度、含水率与三向干缩、弦切径切
2. **常见木种图鉴**——12 张木种卡（木材实照 + 树木实照 + 产地 + 硬度/密度/价格档/稳定性 + 适合与避坑），附 Janka 对比图与硬度×价格性价比地图；含「红木为何不在图鉴里」说明
3. **人造板材**——多层板/指接板（含直拼/明齿/暗齿之分）/大芯板/颗粒板/MDF/欧松板/生态板 + GB/T 39600 环保等级
4. **怎么选**——11 类用途决策表（含攀岩指力板一行）+ 板材市场五个动作（翘曲四形态/活节死节识别）+ 规格计价与代裁封边 + 预算观
5. **怎么用**——环境适应、纹理方向、胀缩留缝、连接方式、表面处理选择表、日常养护

## 数据口径

- Janka 硬度与密度：The Wood Database 通行参考值
- 甲醛限量：GB/T 39600-2021
- 价格档：2026 年国内市场粗略相对分档，仅供比价
